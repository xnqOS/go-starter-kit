这个文件是做什么的？
  • .env.deploy 是线上 API 容器的全部配置。make deploy 用 compose.deploy.yaml 启动容器时把它作为环境变量读进去。它和本地开发用的 .env 是两个文件。
  • 里面有密钥，不要提交到 Git，也不要发到聊天里。这个页面只在本机 127.0.0.1 上运行，地址里的 ?t=… 是一次性口令。
  • 改完后在服务器上重新执行 make deploy 才会生效。只改配置不改代码也要执行。
  • 标为「必填」的不填，API 起不来，或者已经打开的功能没法用。标为「建议」的不填也能启动，但线上会有问题。
  • 「生成」按钮在本机生成随机密钥，和 openssl rand 的效果一样。标明「不要更换」的密钥生成一次以后就不要再换：换了会导致已加密的数据读不出来。
  • 第三方的 key 在每一项下面的「去哪里拿」里写了网址和步骤。
  • 顶部的「API 启动检查」直接调用 API 自己的启动校验（项目配置了的话），结果和 make deploy 时一样。
  • 保存时，如果文件已经存在，旧文件会先备份成 .env.deploy.bak-时间。备份里也有密钥，检查完就删掉。原文件里的注释不会保留；这个页面不认识的变量会原样放在文件最后。
